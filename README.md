## اضافه کردن یک محصول (از سایت GitHub، بدون دستور)

۱. وارد پوشه‌ی `img` شو. بزن **Add file → Upload files**. عکس محصول را بکش و رها کن (مثلاً `newplugin.jpg`). پایین صفحه **Commit changes** را بزن.

۲. فایل `products.json` را باز کن و روی مداد ✏️ بزن. یک محصول کامل را از `{` تا `}` کپی کن. بعد از `}` یک ویرگول `,` بگذار و نسخه‌ی کپی را بچسبان. اسم، توضیح و `img/newplugin.jpg` را عوض کن.

۳. **Commit changes** را بزن. بعد از چند دقیقه، سایت و اپ به‌روز می‌شوند.

اگر اشتباهی تایپ شده باشد (مثلاً یک ویرگول جا افتاده باشد)، سایت خراب نمی‌شود. فقط در تب **Actions** یک ضربدر قرمز می‌بینی.

## تغییر شماره، آیدی، کارت و لینک‌های داخلی

فایل `settings.js` را باز کن، روی مداد ✏️ بزن و فقط متن داخل "گیومه‌ها" را عوض کن. هر چیزی که خالی بماند (`""`) دیده نمی‌شود.
